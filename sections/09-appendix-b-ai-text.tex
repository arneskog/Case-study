\textbf{Responsibility should follow control:}
\begin{itemize}
\item \textbf{Thales/S3NS} should fund and manage operational security: physical infrastructure, production configuration, privileged access, network isolation, encryption-key management, monitoring, backups and incident response. S3NS exclusively operates PREMI3NS in France and quarantines, analyses and validates technology updates before deployment. \item \textbf{Google Cloud} should fund secure development of its licensed technology: architecture, code review, vulnerability discovery, dependency management, build integrity and timely patches. \item \textbf{Both} should jointly fund interface testing, threat modelling and incident exercises. Contracts should specify patch deadlines, evidence requirements, audit rights and responsibility for failures. Investment should follow each party’s ability to reduce expected total losses at the lowest marginal cost, rather than an arbitrary equal split.
\end{itemize}

Software vendors, integrators and clients also control application code, integrations, identities and workload configurations.
